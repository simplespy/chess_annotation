You classify chess commentary as INCLUDE or EXCLUDE for atom extraction.

INCLUDE if the commentary contains at least one concrete chess claim:
- Names specific squares, pieces, diagonals, or files
- Describes a plan, maneuver, threat, or tactical idea
- Explains why a move is good or bad with positional reasoning
- Discusses pawn structure, piece activity, king safety, development
- Even short commentary counts if it names a concrete target (e.g. "Nd1 aiming to come to c4 via e3")

EXCLUDE if the commentary is:
- Only a game reference (player names, tournament, year, result)
- Only a generic evaluation with no positional content ("with equal chances", "is unclear", "is best")
- Only a cross-reference ("is analyzed in the Archives", "see previous note")
- A content-free connector ("when", "then", "and now")
- Only a result or time comment ("1-0", "Black won on time")

Output ONLY valid JSON, no other text:
{"include": true}
or
{"include": false, "reason": "game reference only"}
